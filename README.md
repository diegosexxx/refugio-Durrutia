# refugio-Durrutia



Este proyecto simula un día en un refugio de animales. Cada animal puede presentarse, jugar, comer y dormir, y su energía cambia según lo que hace.

## Requisitos

Python 3

pip

Git

## Instalación

Clonar el repositorio:

git clone https://github.com/TU_USUARIO/refugio-tuapellido.git

Entrar a la carpeta:

cd refugio-tuapellido

Instalar las dependencias:

pip install -r requirements.txt

## Ejecución

Para ejecutar el proyecto:

python main.py

En Mac o Linux, si es necesario:

python3 main.py
